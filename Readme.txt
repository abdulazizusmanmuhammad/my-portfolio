Abdulaziz Usman personal portfolio

This is the static personal portfolio website for Abdulaziz Usman, a Nigeria-based web developer, web designer, and video editor. It is separate from AZ Creation Hub, his agency, which is featured as one project. The site uses Bootstrap and the FolioOne design foundation and is structured to work on GitHub Pages.

Open index.html to preview the site. The contact page includes an email-draft form; there is no server-side contact form.

Adding portfolio projects:
- Save project preview images in assets/img/projects/.
- In portfolio.html, add a project card with its image, title, accurate description, and link. Add verified project context to portfolio-details.html when available.
- The project gallery is a static layout; it does not accept uploads directly from the published page.
